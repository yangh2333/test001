# 集成接口清单

版本：v1.0　日期：2026-11-01　依据：B 组 6 题答案 + D-2（只开放固定端口走网页代理）+ D-4（出网审批由 IT 牵头）

---

## 0. 结论先行

原 v1.2 规划了 7 类集成，回收答案后**只剩 5 条真实接口 + 2 条条件性接口**，另有 3 类**明确不集成**：

| 类别 | 系统 | 结论 |
| --- | --- | --- |
| ✅ 真实集成 | LDAP、企微、CI（Jenkins/GitLab）、xwiki、IT CMDB | 见 §1–§5 |
| ⚠️ 条件性 | AI 大模型 API、供应商回填 / 客户门户 | 见 §6–§7，走固定端口代理 |
| ❌ 明确不集成 | 财务/采购系统（B5）、北森 HR（B6）、ATE 机台系统（B3 外包） | 改为文件导入 / 台账，见 §8 |

---

## 1. LDAP —— 账号主源

| 项 | 内容 |
| --- | --- |
| 方向 | 平台 → LDAP（出向查询） |
| 协议/端口 | LDAPS 636（内网直连，不经代理机） |
| 频率 | 每日 02:00 全量比对 + 工作日每小时增量 |
| 同步字段 | 工号（唯一键）、姓名、企业邮箱、账号状态（启用/禁用）、所属 OU |
| 写入 | **只读**，平台不回写 LDAP |
| 冲突处理 | 与企微组织树不一致时进「同步冲突」待办，PMO 人工裁决；账号状态以 LDAP 为准 |
| 失败降级 | 连续 3 次失败 → 冻结同步并告警；已同步用户可正常登录，新增/离职暂不生效 |
| 责任方 | IT（提供只读账号与 OU 结构） |

## 2. 企业微信 —— 组织树 + 消息

| 项 | 内容 |
| --- | --- |
| 方向 | 双向（平台 ← 通讯录；平台 → 消息卡片） |
| 协议/端口 | HTTPS 443，**仅 `qyapi.weixin.qq.com` 白名单**，经代理机出网 |
| 频率 | 通讯录每日同步；消息实时 |
| 同步字段 | 部门树、成员与部门关系、在职状态、头像、手机号（按需） |
| 推送内容 | 待办卡片、审批卡片、Gate 结论、风险超期、工单 SLA 超时 |
| 失败降级 | 消息失败 → 降级为邮件（重要通知）或站内消息；重试 3 次后入死信队列 |
| 责任方 | IT（应用授权与 IP 白名单）+ PMO（消息模板治理） |

## 3. Jenkins / GitLab CI —— 构建发布状态

| 项 | 内容 |
| --- | --- |
| 方向 | **单向入站**：CI → 平台（Webhook） |
| 协议/端口 | HTTP/HTTPS，内网固定端口（如 8080 或 443 内网段），**不出代理机** |
| 触发 | 构建成功/失败、发布到指定环境 |
| 回写字段 | 里程碑/任务 → 最近构建状态、构建号、制品版本；**不反向操控流水线** |
| 失败降级 | Webhook 失败不影响 CI；平台侧状态保持"未知"并标记数据陈旧 |
| 责任方 | 各 BU 的 CI 管理员（配置 Webhook），平台提供接入文档 |
| 前提（B2） | 需各 BU 愿意配置；**若某 BU 不配，则该 BU 的发布状态手工填报** |

## 4. xwiki —— 文档单点

| 项 | 内容 |
| --- | --- |
| 方向 | SSO 单点登录（不迁移内容） |
| 协议 | LDAP / OAuth 2.0 单点；平台只生成**目录链接与命名规范** |
| 同步内容 | 无内容同步；平台按项目模板生成目录结构建议（文档实体仍在 xwiki） |
| 失败降级 | 单点失败 → xwiki 独立登录可用，平台内链接降级为跳转首页 |
| 责任方 | IT（配置单点）+ PMO（目录规范） |
| 注意（E4） | 企微与 xwiki 目前未绑定，两者各自独立对接平台，不做三方联动 |

## 5. IT CMDB —— 集群资产只读

| 项 | 内容 |
| --- | --- |
| 方向 | 平台 ← CMDB（只读拉取） |
| 协议/端口 | 内网 HTTPS 固定端口或数据库只读视图 |
| 频率 | 每日一次 |
| 同步字段 | 服务器/集群资产编号、规格、所属部门、状态、位置 |
| 用途 | 集群调测类项目的资源申请与展示（B3：服务器集群在 IT 侧可打通） |
| 失败降级 | 数据陈旧标记；集群资源申请转人工工单 |
| 责任方 | IT（提供只读接口） |

## 6. AI 大模型 API（条件性，P1 启用）

| 项 | 内容 |
| --- | --- |
| 方向 | 平台 → 代理机 → 外网 API（**出向**） |
| 端口 | 443，**仅白名单域名**，经 DMZ 代理机 |
| 脱敏规则 | 请求前剥离：项目真实名称（替换为编号）、人名（替换为角色）、成本/预算数值；响应后按编号回填 |
| 配额 | 按人/按天限流；月度费用看板；超预算自动降级为模板化输出 |
| 审批 | **出网合规审批由 IT 牵头**（D-4），安全部门会签，PMO 备案 |
| 供应商 | 至少 2 家热备，防止单点涨价或中断 |
| 日志 | 每次调用留存请求摘要（不含原文）与 token 用量，留存 180 天 |

## 7. 供应商回填 / 客户门户（条件性，走固定端口入站）

| 项 | 供应商批次回填 | 客户门户 |
| --- | --- | --- |
| 阶段 | P2（一期先用邮件回执解析，见下） | P2/P3（A6/E3 需求，需独立立项） |
| 端口 | DMZ 代理机单端口 HTTPS 入站 | DMZ 代理机单端口 HTTPS 入站 |
| 认证 | 独立账号池 + MFA，**不走 LDAP/企微** | 独立账号 + MFA + 邀请链接 |
| 可见范围 | 仅本项目的批次表单字段（字段级白名单） | 交付计划 / 验收进度 / 问题单，只读 + 电子签认 |
| 禁看 | 成本、资源、其他项目 | 内部资源、成本、其他客户 |
| 审计 | 每次访问与提交全量留痕 | 同左 |
| 一期替代方案 | **邮件回执自动解析入库**：向供应商下发固定模板回执单，平台解析邮件生成批次状态（E1，零端口开放，建议优先做） | — |

## 8. 明确不集成的三类（改为文件/台账）

| 系统 | 原因 | 替代方案 |
| --- | --- | --- |
| 财务 / 采购（B5） | 独立系统，项目成本只做文件输入，不互联 | 月度成本台账 Excel 导入；预算与成本在平台内手工维护 |
| 北森 HR（B6） | 明确表示不太可能集成 | 技能标签库纯自建（PMO 治理字典）；请假数据 Excel 导入；可用工时 = 标准工时 − 承诺工时 |
| ATE 机台（B3） | **机台是外包的**，无自有系统可对接 | 改为外包厂商的产能 / 批次 / 结算台账；记录投料—出片—交期与费用，不做内部排期 |

## 9. 端口总表（D-2 落地）

| 方向 | 用途 | 端口 | 目标 | 是否经代理机 |
| --- | --- | --- | --- | --- |
| 内网 | 用户访问平台 | 443（内网） | 应用节点 | 否 |
| 出向 | 企微 API | 443 | qyapi.weixin.qq.com | **是（白名单）** |
| 出向 | AI 大模型 API | 443 | 白名单域名（≤2 家） | **是（白名单 + 脱敏）** |
| 入向 | 供应商批次回填 | 单端口 HTTPS | 受限服务 | **是（DMZ 终结）** |
| 入向 | 客户门户 | 单端口 HTTPS | 受限服务 | **是（DMZ 终结）** |
| 内网 | LDAP | 636 | LDAP 服务器 | 否 |
| 内网 | CI Webhook | 内网固定端口 | 应用节点 | 否 |
| 内网 | CMDB / xwiki | 内网固定端口 | 各系统 | 否 |
| — | **其余全部** | **关闭** | — | — |

**代理机要求**：独立主机、双网卡、仅运行 Nginx/正向代理与 WAF 规则、不落业务数据、日志留存 180 天、规则变更需双人审批。
